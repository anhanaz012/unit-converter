# Unit Converter

A simple unit converter built with HTML, CSS, JavaScript, and Node.js.
Idea from : https://roadmap.sh/projects/unit-converter

## Features

* Length conversion: mm, cm, m, km
* Weight conversion: mg, g, kg
* Temperature conversion: °C, °F, K
* Client-side input validation
* Conversion handled by a Node.js backend

## Run

Start the Node.js server:

```bash
node server.js
```

Then open the frontend using a local server such as VS Code Live Server.
